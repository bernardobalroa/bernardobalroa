# AI-Powered Agency Management Platform

This repository contains the source code for the AI-Powered Agency Management Platform.

## Project Overview

This platform aims to combine project management, content workflow, client relationship management, and AI-driven insights into a single web application. It is designed for internal agency team members to manage tasks, collaborate on content, integrate with social media, and provide clients with dedicated portals.
